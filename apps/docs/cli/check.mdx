---
title: "openlabel check"
description: "Judge every claim in a piece against the drug's label."
---

```sh
openlabel check <file> --label <drug or set id> [options]
```

`<file>` is plain text, Markdown or HTML. HTML is reduced to its visible text, one line per block element, with scripts and styles dropped.

| Option | Description |
| --- | --- |
| `--label <drug>` | Required. A brand name such as `dupixent`, or a DailyMed set id |
| `--label-version <n>` | Judge against a past version of the label instead of the current one |
| `--rules <file>` | A YAML [rule pack](/concepts/rule-packs). Defaults to `fda-core` |
| `--save` | Also write the report to `<file>.check.json` for [`watch`](/cli/watch) |
| `--json` | Print the report as JSON |
| `--model <id>` | Claude model. Defaults to `claude-opus-5-5` |

```sh
openlabel check examples/dupixent-sms.txt --label dupixent --rules examples/pulse-sms.yaml
```
