## Pinned datasets

CMS publishes each year of Part D and Open Payments as its own dataset with its own id. Those ids are pinned in `packages/unseen/src/partd.ts` and `packages/unseen/src/payments.ts`, and were checked against the live APIs: the Part D file name ends in `DY24`, data year 2024, and each Open Payments id returned rows for its own program year.

When CMS publishes the next year of either, add its id there.

## What the model sees

Check sends the model the piece and, for each claim, the twelve label sentences retrieval chose. Unseen sends the model only your question. Neither sends patient data, because none of these sources contain any.
